# 事件→个股映射的可靠性分级（动作 1）

> 完成时间：2026-11-04
> 改动文件：`databridge/policy_radar.py`、`databridge/event_ledger.py`
> 对应问题：**"如何确定这个政策/国际政治事件会影响具体这只股票？"**

---

## 一、先给结论：这个问题不能"确定"，只能"分级"

我实测了同一事件、同一股票、同一 prompt，**跑 8 轮**：

| 结果 | 次数 |
|---|---|
| 判为「利好」 | **6** |
| 判为「不确定」 | 1 |
| 判为「完全不相关」（空数组） | **1** |

**8 轮给出 8 个不同的理由**：

- "节能改造可降低电耗成本"（利好）
- "节能改造**或推高资本开支**"（不确定）
- "与公司无直接关系"（不相关）

**所以"AI 判断某政策是否影响某股票"本身是概率性的，不是确定性的。**
往前加一句"确定"是自欺欺人。**能做的是把可靠性显式标注出来，让你知道哪条能当真。**

---

## 二、分级标准（以**可核对的证据**为准，不听 AI 自评）

| 等级 | 标签 | 判据 | 可复现 |
|---|---|---|---|
| **A** | 实锤 | 事件主体**就是这只股票**（公司自己的公告） | ✅ 完全 |
| **B** | 强映射 | 事件板块与个股行业/概念**字面精确命中** | ✅ 完全 |
| **C** | 弱映射 | 仅**同义词**命中、仅子串模糊命中，或 AI 明说"间接" | ⚠ 部分 |
| **D** | 推测 | AI 判"无落地路径"，或方向不确定 | ❌ 会变 |

> 2026-11-08 修订：**同义词命中从 B 降到 C**。原因是同义词表里混着
> **包含/上下游**关系（"算力"↔"通信设备"、"半导体"↔"光模块"），
> 把它和字面命中记成同一强度，会让一条算力政策自动给整个通信设备行业记 B 级。
> 详见第五节。

### 关键设计：等级**由匹配到的证据决定**，不由 AI 自己说了算

```python
# 命中强度判定（_matched_labels），五档
"数据中心"  ==  "数据中心(AIDC)"      → exact_concept   （去括号后字面相同 → B）
"券商"      ∈   {"券商","证券",...}   → synonym_concept （同义词组命中 → 最高 C）
"算力"      ≈   "通信设备"（同组）     → synonym_industry（包含关系，同样是 C）
"算力"      ⊂   "算力租赁"            → partial         （子串包含 → 最高 C）

# 定级（grade_mapping）
exact + AI说"直接/间接"  → B
exact + AI没给 link      → C（保守）
只有 synonym / partial   → C
AI说"无"                 → D
```

同一板块词在行业与概念上都命中时，取**更强**的那条作为证据：
中际旭创的行业是"通信设备"（与"算力"只是同义关系），但它有字面命中的概念
"算力" —— 记录的是 `exact_concept` 而不是 `synonym_industry`。
否则"东方财富"靠"人工智能"概念就能被算成算力受益。

**为什么不让 AI 自评等级？** 因为 AI 有"讨好倾向" —— 让它自己评级，它会把"间接"也说成"直接"。所以等级按**文本匹配的客观事实**算，AI 只负责判断"直接/间接/无"，且这个判断本身要接受"说无就降 D"的约束。

```

    依据: 精确命中:半导体；AI判定:间接

    依据: 精确命中:信创；AI判定:间接
[B] 605366.SH 宏柏新材     【强关联】▲ 利好·地缘 | 美中期选举民主党超预期
    依据: 精确命中:风电；AI判定:间接
```

**告警文案里直接带等级标签**（`【实锤】/【强关联】/【弱关联·推测】/【推测·参考】`），
同时写了 `mapping_basis` 字段说明**依据是什么**，可自己核对：

```json
{
  "mapping_level": "B",
  "mapping_level_desc": "强映射（事件板块与该股主营/概念精确命中）",
  "mapping_basis": "精确命中:算力；AI判定:间接",
  "ai_link": "间接"
}
```

C/D 级还会**自动降一级严重度**（critical → warn），避免和 A/B 的实锤混在一起。

## 四、配套改动：AI prompt 增加了 `link` 字段

原来的 prompt 只要求"direction + reason"，现在强制要求：

```
"link": "<直接|间接|无>"
```

并给了**三档的具体判据和反例**：

| link | 定义 | 例子 |
|---|---|---|
| **直接** | 事件的扶持/限制对象**本身就是这只股票的主营业务** | 算力节能改造 → 中国移动运营数据中心，改造直接落在电费上 |
| **间接** | 需 1~2 层传导，或依赖边缘业务 | 建农产品批发市场 → 冷链设备需求 → 格力有商用冷链业务 |
| **无** | 找不到落到收入/成本/订单/产能的路径 | 美联储加息 → 压制风险偏好 → 利空券商 |

**并明确写了"宁可少报，不要把'无'写成'间接'"。**

## 五、同义词组：既是修补，也是限制

实测发现：东方财富的行业标签是「**证券**」，事件板块写「**券商**」，
**同义但无子串重叠** → 原逻辑判为不相关 → 本该 B 级的映射被降成 D。

现在 `policy_radar.py` 和 `policy_calendar.py` **共用同一份 14 组同义词表**：

```python
{"券商", "证券", "非银金融", "保险", "多元金融"}
{"算力", "数据中心", "云计算", "IDC", "通信设备", "人工智能"}
...
```

**但这张表本身是"为了不漏报"而放宽的，其中有几组并不是严格同义：**

| 关系 | 例子 | 处理 |
|---|---|---|
| 真同义 | 券商 / 证券 | 仍算线索，但按 C 级 |
| 包含 / 上下游 | 算力 ⊃ 数据中心；半导体 ⊃ 光模块 | 按 C 级，理由里写明"仅同义词命中" |
| 跨类合并 | 算力 ↔ 通信设备 ↔ 人工智能 | 同上 |

所以同义词命中**可以出现，但不能单独支撑强证据** —— 明细里会写
`同义命中:通信设备`，用户一眼能看出这条是靠词表而不是靠事实连上的。

## 七、你现在就能用的判断方法

在数据攒够之前，可以手工用一句话自查每条告警：

> **这条影响能不能落到「钱」上？**

- ✅ "中国移动运营数据中心 → 节能改造降低电费" → **落到成本上，可信**
- ❌ "美联储加息 → 压制风险偏好 → 利空券商" → **落到"偏好"这种虚的东西上，基本是噪音**

**落到收入 / 成本 / 订单 / 产能的，可信；落到情绪 / 偏好 / 预期的，是噪音。**

## 八、如实标注的限制

| 限制 | 说明 |
|---|---|
| **D 级仍会输出** | 只是标了"推测"，没有滤掉。因为怕漏报 —— 但你可以无视 D 级 |
| **link 仍是 AI 判断** | 只是"说无就降级"这一条约束，AI 说"直接"时仍可能过度乐观 |
| **A 级目前只覆盖公告** | 政策类事件极少直接点名个股，所以 A 级基本只有公司公告 |
| **8 轮实测的样本很小** | 那 8 轮只测了 1 个事件 × 1 只股票，不足以代表全部 |
| **分级有效性未验证** | C 节样本全 0，暂时无法证明"B 比 D 好" |
