## 二、真正的缺口（按对分析的价值排序）

### 🔴 缺口 1：历史估值序列（仅快照，无法看分位）

**现状：** `ext_valuation` 是 snapshot 模式，**只有今天的 PE/PB**。

**缺失能力：** 回答不了「这只股票当前的 PE 处于自身历史什么分位」。

**为什么重要：**

我们之前做低估值因子 IC 检验时，只能用 `PB = 收盘价/净资产` 重建。**真正的价值投资判断需要「历史分位」，而不是「绝对值」。**

例：PE=20 是贵还是便宜？取决于它历史上是 10 还是 40。

**可获取性（实测）：**

```
✅ ak.stock_a_ttm_lyr()  → 263 行，可回溯到 2005 年
   列: date, middlePETTM, averagePETTM, middlePELYR,
       quantileInAllHistoryMiddlePeTtm,
       quantileInRecent10YearsMiddlePeTtm, ...
```

**这是全市场维度的历史 PE，自带历史分位。**

**但个股历史 PE 的接口未找到**（`stock_a_indicator_lg` 在新版 akshare 已移除）。

**建议方案：** 自建时序。把当前快照表改成 timeseries 模式，每日累积 —— **你已经有定时任务，只需改一处配置，跑几个月就有历史了**。

### 🔴 缺口 2：分钟数据（名义 15 天，实际 0 只覆盖）

**现状实测：**

```
minute 表: 15 天历史，symbols_covered = 0
实测单只股票查询: 只返回 1 条（当前时刻 09:31）
```

**缺失能力：** 日内形态分析、分钟级策略回测、VWAP 计算。

**为什么重要：** 上游新增了「分钟量价策略」，**但没有分钟数据，这个功能用不了**。

**成本：** TdxQuant 只提供 40 天深度。要更多需要付费源。

**建议：** 如果不是做日内交易，**优先级低**。

### 🟡 缺口 3：两融余额（可获取，未接入）

**实测：**

```
✅ ak.stock_margin_sse()        → 19 行（日期/融资余额/融资买入额/融券余量）
✅ ak.stock_margin_detail_szse() → 2,118 行（个股级：融资买入额/融资余额/融券卖出量）
```

**缺失能力：** 杠杆资金动向。

**为什么重要：**
- 融资余额快速上升 = 杠杆资金涌入（可能是炒作，也可能是趋势）
- 融券余额上升 = 有人在做空

**你的自选股分析里完全没这个维度。**

**成本：低**（akshare 直接有，一次拉完）。

**分钟数据** —— 成本高（需付费源），而且你不做日内交易的话用不上。

## 五、诚实提醒

**补数据提升的是「排雷能力」，不是「预测能力」。**

上面 9 个缺口里，能明确提升决策质量的只有三个：

| 缺口 | 能帮你避开什么 |
|---|---|
| **股东增减持** | 大股东在减持的股票 |
| **两融** | 杠杆资金正在撤离的股票 |
| **涨停原因** | 纯情绪炒作 vs 真有基本面 |

**其余（如机构调研、资金流）的信号强度都偏弱，我们之前的因子检验已经证明技术类因子 IC 普遍为负。**

**而「历史估值分位」是唯一有可能提升「选股」能力的** —— 因为你之前已经验证过，低估值因子（BP）的 IC 是正向的（+0.0421～0.0825）。历史分位能让这个因子更精确。
