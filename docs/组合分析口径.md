# 组合分析口径：实际持仓 / 自选观察 / 调用方权重

> 起因：此前风险接口对「自选清单」也算集中度、相关性、回撤预算，结果看起来像一份真实组合报告。
> 但自选清单没有权重、没有成本、没有持仓期限 —— 这些结论在没有真实仓位时没有意义。
> 现在三者必须能一眼分辨，且**不允许**把自选清单说成组合。

## 三种口径

| basis | 标签 | 数据来源 | 权重含义 | 有成本/期限 |
|---|---|---|---|---|
| `actual_positions` | 实际持仓分析 | `data/paper/accounts/<acc>/positions.json` | 市值 / 账户权益 | 有（`avg_cost`、`holding_days`） |
| `watchlist_observation` | 自选股观察（不是组合） | 调用方传入的 symbols | 等权假设 | 无 |
| `caller_supplied_weights` | 调用方提供的权重（未核对账户） | 调用方传入的 weights | 调用方给的数字 | 无 |

`watchlist_observation` / `caller_supplied_weights` 一律带 `is_portfolio: false`、`verified_against_account: false`
与一句 `warning`，调用方（含前端）**不需要**自己判断口径，读 `basis` 即可。

## 关键口径决定

1. **权重分母是账户权益（现金 + 市值），不是持仓市值之和。**
   若按持仓市值之和归一化，一个 90 万现金 + 2 万持仓的账户会被算成「满仓 2 只」。
   实测：现金 90 万、持仓 2 万 → 权重约 2.17%，而不是 100%。

2. **持仓期限取该持仓最早一笔 `lots[].date`**，按自然日计算；缺失时 `holding_days = null`，
   不假装是 0 天（0 天会被误读成"今天刚买"）。

3. **没有实时价时用最近日线收盘价**，并把这件事写进 `limitations`，不静默替换。

4. **权益为 0、缺成本、缺 lots 都在 `limitations` 里逐条列出**，不阻断出报告。

5. **不确定的权重不进风险模型**：`holdings_for_risk()` 只输出 weight 非空的持仓
   （"权重未知时不能编一个权重喂给风险模型"）。

## 账户选择

`resolve_account(data_dir, account_id=None)`：

- 显式给 `account=` → 用它；
- 不给 → 取**权益最大的有持仓账户**，并在 `note` 里说明取了哪个、怎么指定；
- 一个都没有 → 回退 `paper.DEFAULT_ACCOUNT_ID` 并说明找不到有持仓的账户。

实测本机账户：`acc_mvxyztiip`（现金 523281.45、10 笔持仓）等 7 个。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/risk/positions` | 实际持仓明细：权重/成本/市值/持仓期限/lots 数；可选 `account=` |
| GET | `/api/risk/portfolio` | `account=` 与 `symbols=` **必须且只能给一个**，否则 400 |
| POST | `/api/risk/portfolio` | 调用方给 holdings → `caller_supplied_weights` |

`GET /api/risk/portfolio?account=…` 走真实持仓，`weight_basis = "market_value / account_equity"`，
并附带 `account_id`、`positions_fed`；该账户没有持仓时 400「没有可用于组合分析的持仓」。

## 已覆盖的测试（`backend/tests/test_portfolio_positions.py`，15 项）

- 权重分母是权益（90 万现金 + 2 万持仓 → 2.17%）
- 持仓期限取最早 lot；缺 lots / 缺成本 / 权益为 0 / 用收盘价 都只记 limitation
- 按权重降序；`resolve_account` 取最大权益、空目录不崩
- `observation()` 不是组合、无权重时不给 `weights` 键
- `holdings_for_risk()` 跳过未知权重
- API：`account=` → `actual_positions` 且无 warning；`symbols=` → 观察口径且带 warning；
  `weights=` → `caller_supplied_weights`；两者都给或都不给 → 400；空仓账户 → 400；POST → 调用方口径

定向回归：`pytest tests/test_portfolio_positions.py tests/test_risk_api.py tests/test_openapi_contract.py tests/test_portfolio_risk.py -q` → 49 passed。

## 已知限制

- **ETF 仍按自身持仓展开，不是组合层面的行业穿透**：账户里持有 ETF 时，`load_actual_positions`
  给的是 ETF 这一行的权重，其成分股风险敞口没有展开（「带生效日期的成分股快照 + 事件暴露」
  已在告警链路落地，见 [告警字段契约](告警字段契约.md) 第十节；组合层面的行业穿透仍未做）。
- 持仓期限是**自建仓起的自然日**，不区分部分减仓；`lots` 只反映买入批次。
- 观察口径的「等权假设」只是为了让集中度/相关性有输入，**不是**建议的配置比例。
- 本文件只覆盖口径分离；ETF 暴露与事件关联的计算另见后续文档。
