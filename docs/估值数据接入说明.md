# 估值数据（PE/PB）接入说明

> 完成时间：2026-11-03
> 数据源：腾讯行情接口（免费、无需注册、无需 Key）
> 落地位置：TSP 扩展表 `ext_valuation`

---

## 一、为什么补这个

**在此之前，系统里完全没有任何估值数据：**

```
total_shares   有
float_shares   有
market_cap     无
pe / pb        无
```

**后果：**
- 无法判断"现在贵不贵"
- 因子体系里的 `pb_latest` 因为数据几乎为空（覆盖率 0.45%）而失效
- 我们分析北部湾港时把 PB 算成约 1.0，实际是 2.16

**现在补上了。**

---

## 二、数据源说明

**接口：** `https://qt.gtimg.cn/q=<代码列表>`

**特点：**
- ✅ 免费，无需注册、无需 API Key
- ✅ 支持批量（60 只/次，实测 90ms）
- ✅ 返回 PE(TTM)、PB、总市值、流通市值、换手率、成交额
- ⚠️ 返回 GBK/GB18030 编码，需转码
- ⚠️ 数据为**实时快照**，不是历史序列

**字段位置（按 `~` 分割后）：**

| 索引 | 含义 |
|---|---|
| 1 | 名称 |
| 3 | 最新价 |
| 37 | 成交额（万元） |
| 38 | 换手率（%） |
| **39** | **市盈率 TTM** |
| 44 | 流通市值（亿） |
| 45 | 总市值（亿） |
| **46** | **市净率** |
| 47 / 48 | 涨停价 / 跌停价 |

**验证：** 茅台 PE 22.52、PB 6.82；用系统财务里的 BPS 216.95 反算 `1480/216.95 = 6.82` —— **完全吻合**。

## 三、已完成的配置

### 1. 扩展表 `ext_valuation`

| 字段 | 类型 | 含义 |
|---|---|---|
| symbol | string | 标准代码（内部自动） |
| name | string | 名称 |
| price | float | 最新价 |
| **pe_ttm** | float | **市盈率 TTM** |
| **pb** | float | **市净率** |
| total_mv | float | 总市值（亿） |
| circ_mv | float | 流通市值（亿） |
| turnover | float | 换手率（%） |
| amount | float | 成交额（万） |

**覆盖：5569 只，拉取耗时 7.1 秒。**

### 2. 刷新脚本

```
scripts/fetch_valuation.ps1
```

**手动执行：**
```powershell
pwsh -NoProfile -File "D:\deepseek_path\tick-stock-panel\scripts\fetch_valuation.ps1"
```

**注意：** 脚本会先调用 `/api/ext-data` 创建表，若表已存在会返回错误但不影响后续写入（可忽略）。

### 3. 定时任务 `TSP-Valuation-Refresh`

| 触发器 | 时间 |
|---|---|
| 每周一至周五 | **16:05**（收盘后） |
| 登录时 | 延迟 3 分钟后 |

**验证：** 手动触发返回 `结果: 0`（成功），下次运行 2026-11-04 16:05。

## 四、怎么用

### 方式 1：查询接口

```bash
GET /api/ext-data/ext_valuation/rows?limit=6000
```

### 方式 2：用于股票扫描

在 `/api/screener/run` 里加 `ext_columns`：

```json
{
  "conditions": ["signal_ma20_breakout"],
  "ext_columns": "ext_valuation.pe_ttm",
  "limit": 30
}
```

**返回结果会多出 `ext_valuation__pe_ttm` 列。**

### 方式 3：AI 助手

AI 助手能直接读取扩展表数据（它有对应工具）。

## 六、已知局限

**1. 只有快照，没有历史序列**

当前只能看"现在的 PE/PB"，**不能算"当前 PE 处于自身历史什么分位"**。

**要补历史估值，需要另找数据源**（或每日跑一次任务、自己累积成时序表，把 `mode` 改成 `timeseries`）。

**2. 依赖第三方接口，可能变动**

腾讯行情接口是公开接口，非官方承诺。**如果接口变更，脚本需要调整字段索引。**

**3. 不支持港股/美股**

只覆盖 A 股（含北交所）。

**4. PE(TTM) 的口径**

腾讯的 PE 是 TTM（滚动 12 个月），**与部分软件显示的"静态 PE"或"动态 PE"不同**，对比时要注意口径。

**5. 亏损公司的 PE 为负数**

筛选时要注意先过滤 `PE > 0`，否则负 PE 会混进"低估值"结果里。

## 七、后续可以怎么扩展

**同一套机制可以再补：**

| 想补的数据 | 可能的免费来源 |
|---|---|
| 历史 PE/PB 序列 | 自建时序表（每日跑一次累积） |
| 股息率 | 腾讯接口字段（需另找索引） |
| 行业估值对比 | 结合已有 `ext_hy_ths` 行业表 |
| 北向资金 | 另找免费接口 |
| 股东户数 | 另找免费接口 |

**关键：扩展表机制已经跑通，后面补数据只需改字段定义和取值逻辑。**
