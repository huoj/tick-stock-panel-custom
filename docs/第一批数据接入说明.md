## 二、字段说明

### ext_insider（股东增减持）

| 字段 | 含义 |
|---|---|
| insider | 变动人姓名 |
| position | 职务（董事长/高管/监事…） |
| relation | 与董监高关系（本人/子女/配偶…） |
| **direction** | **增持 / 减持** |
| delta_shares | 变动股数 |
| avg_price | 成交均价 |
| delta_amount | 变动金额 |
| delta_pct | 变动比例（%） |
| hold_after | 变动后持股 |
| reason | 变动原因（集中竞价/大宗交易…） |
| trade_date | 变动日期 |
| **net_shares_90d** | **近90天净增持股数**（负=净减持） |
| **net_amount_90d** | **近90天净增持金额** |
| cnt_90d | 90天内变动次数 |
| last_date | 最近一次变动日 |

**为什么重要：** 这是**内部人信号**。董监高最了解公司，他们买/卖比任何技术指标都直接。

**之前的问题：** 分析宏柏新材时，系统里查不到「控股股东减持」，只能靠外部新闻。

### ext_margin（两融余额）

| 字段 | 含义 |
|---|---|
| fin_balance | 融资余额 |
| fin_buy | 融资买入额 |
| fin_repay | 融资偿还额 |
| short_qty | 融券余量 |
| short_balance | 融券余额 |
| total_balance | 融资融券余额 |
| **fin_net_buy** | **融资净买入额**（买入−偿还） |
| **net_ratio_pct** | **净买入占余额比（%）** |
| margin_date | 交易日期 |
| market | 深市 / 沪市 |

**为什么重要：**
- 融资余额快速上升 = 杠杆资金涌入
- **净买入占比高 = 当日杠杆资金主动加仓**
- 融券余额上升 = 有人在做空

**覆盖：** 深市 2,118 只 + 沪市 2,000 只 = **4,118 只**

### ext_ztlimit（涨停梯队）

| 字段 | 含义 |
|---|---|
| close / chg_pct | 最新价 / 涨跌幅 |
| amount / circ_mv / turnover | 成交额 / 流通市值 / 换手率 |
| **seal_fund** | **封板资金**（越大越强） |
| first_seal / last_seal | 首次 / 最后封板时间 |
| **break_cnt** | **炸板次数**（0=未开板） |
| **boards** | **连板数** |
| zt_stat | 涨停统计（如 7/4） |
| industry | 所属行业 |
| **reason** | **入选理由**（60日新高且近期多次涨停 等） |
| zt_date | 数据日期 |
| **from_previous** | **是否昨日涨停**（1/0） |

**为什么重要：** 原来你只有「连板梯队」知道谁涨停，**现在知道封板强度、炸板次数和入选理由**。

## 四、技术实现：踩的 3 个坑

### 坑 1：两融数据是 T+1 发布

**现象：** 当天查询返回 0 行

```
20261104 深市: 0 行     ← 今天还没有
20261103 深市: 2118 行  ← 昨天有
```

**解决：** 自动回溯最多 7 天，找到最近可用交易日。

### 坑 2：沪深混合批次导致 500

**现象：**

```
深市 2118 行 + 沪市 2000 行 → 单批写入 → 500 Internal Server Error
```

**根因：**

```
polars.exceptions.ComputeError: could not append value:
7.386579e7 of type: f64 to the builder;
make sure that all rows have the same schema
```

**深市有 `total_balance`/`short_balance`，沪市这些字段为 None** —— 同一批内 polars 推断出两种 schema。

**解决：深市、沪市分开批次写入。**

```python
for tag, chunk in (("深市", rows_sz), ("沪市", rows_sh)):
    call("/api/ext-data/ext_margin/ingest", {"rows": chunk})
```

### 坑 3：涨停原因接口没有「原因」字段

**现象：** `stock_zt_pool_em` 的 16 个字段里**没有「涨停原因」**。

**解决：** 改用 `stock_zt_pool_strong_em`，它有 **「入选理由」** 字段（124 行）。

**合并策略：**
```
stock_zt_pool_em       → 封板资金、炸板次数、连板数
stock_zt_pool_strong_em → 入选理由（覆盖到同 symbol 的行）
stock_zt_pool_previous_em → 标记 from_previous=1
```

**最终合并 156 只。**

## 七、已知局限

| 局限 | 说明 |
|---|---|
| **股东增减持只保留近 90 天** | 历史数据在源里有 17.3 万行，我只聚合了近 90 天的 2,099 行 |
| **两融是 T+1** | 当天拿不到当天数据，最多回溯 1 天 |
| **两融沪市缺 `short_balance`** | 沪市接口不返回融券余额，只有融券余量 |
| **涨停梯队只有当日** | 要历史需按日期逐个拉 |
| **`ext_insider` 是聚合口径** | 每只股票只保留最近一次变动的详情 + 90 天汇总，明细未存 |
