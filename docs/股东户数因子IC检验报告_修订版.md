## 一、数据质量问题与修正

### 问题 1：新股上市首期导致变动率异常

**原始数据里最高变动率是 3,214,000%。**

**根因：新股上市首个报告期，"上期户数"接近 0，除法爆炸。**

| 区间 | 行数 | 占比 |
|---|---|---|
| \|变动率\| > 100% | 1,688 | **1.54%** |
| \|变动率\| > 1000% | 251 | 0.23% |

**典型样本：**
```
301552.SZ  变动率 +153,944%
301603.SZ  变动率 +336,260%
603391.SH  变动率 +321,583%
```

### 问题 2：`股东户数-上次` 不保证是"上一季度"

**akshare 返回的"上期户数"可能来自任意历史时点**（实测截止日跨度 2013-2026）。

**修正：改用历史季度文件自算变动率，强制要求间隔 80-100 天。**

### 问题 3：分母过小

**holders < 500 的记录不可比，一并剔除。**

### 修正后的清洗规则

```python
# 1. 间隔必须是一个季度
ok = (gap_days >= 80) & (gap_days <= 100)
# 2. 上期户数必须足够大
ok &= (prev_holders >= 500)
# 3. 变动率绝对值上限
chg = where(ok, (holders/prev_holders - 1) * 100, NaN)
chg[|chg| > 100] = NaN
```

**清洗结果：53,154 行 → 有效 46,627 行（87.7%），过滤 6,527 行（12.3%）。**

## 六、双因子组合检验（新增）

**户数集中度 + 低估值 BP 的组合。**

| 配置 | IC | IR | 胜率 | t |
|---|---|---|---|---|
| 户数集中度（单） | +0.0421 | **+0.676** | 68.2% | +3.17 |
| BP（单） | +0.0685 | +0.313 | 57.9% | +1.37 |
| **z-score 等权合成** | **+0.0614** | **+0.424** | 63.2% | +1.85 |

## 结论：组合没有提升，反而变差

**合成的 IR（+0.424）低于户数单因子（+0.676）。**

**原因：BP 因子本身信噪比低（IR 0.313、t 仅 1.37），等权合成被它拖累了。**

**双重排序（3×3=9 组合）的最优是 G3_B2（年化 21.06%），但这需要同时满足两个条件，实际可得的股票只有 561 只，且没有比单因子更好。**

**所以：不建议组合使用。户数因子单独用更稳定。**

## 七、净收益核算（关键：基准对比）

### 7.1 成本核算

**按实际持仓变动计算真实换手率：**

```
月调仓，单边换手率 26.7% → 年换手 321%
卖出单边成本 0.125%（佣金0.025% + 印花税0.05% + 滑点0.05%）
买入单边成本 0.075%（佣金0.025% + 滑点0.05%）
年化成本 0.64%
```

**成本远低于我之前估算的 4.8%** —— 因为 977 只的大组合每月只换 27%，比我假设的低得多。

## 十、对"只买几只股票"的人怎么用

**这个因子的横截面用法（买 Top20% 的 977 只）你做不到。**

**但它的方向性结论可以用作「排除条件」：**

```
户数大幅增加（> +20%）→ 散户在接盘 → 提高警惕
户数大幅减少（< -10%）→ 筹码在集中 → 相对积极
```

**自选股实测：**

| 股票 | 户数变化 | 解读 |
|---|---|---|
| 中国移动 | **-17.05%** | 集中，属 Q1 附近 |
| 格力电器 | **-13.79%** | 集中 |
| 东方财富 | -4.01% | 温和集中 |
| 水井坊 | -3.84% | 温和集中 |
| 美的集团 | -0.89% | 持平（**数据为 2026-02，已过期**） |
| **宏柏新材** | **+47.95%** | **分散，属 Q5** |

**宏柏新材是唯一落在 Q5 的，而 Q5 的历史年化只有 10.70%、波动 24.86%。**

## 十一、技术实现说明

**因子已正式注册进系统：**

```
表:  ext_gdhs_ts (mode=timeseries)
字段: holders, gdhs_chg, gdhs_concentration, gdhs_inv_chg
因子ID: ext_ext_gdhs_ts_gdhs_concentration 等 4 个
覆盖: 477 个交易日分区 / 249 万行（已前向填充）
```

**为什么需要前向填充：**

季度可用日（如 2026-11-14）大多不是交易日，timeseries 精确对齐会导致覆盖率仅 1.22%。
填充方式：每个交易日取"该日已知的最新一期"，符合 PIT 契约。

**现在可在扫描器直接用：**

```json
{"ext_columns": "ext_gdhs_ts.gdhs_concentration"}
```
